# RECIPE DATABASE


## Instructions for Build and Use
Steps to build and/or run the software:

1. Navigate to the recipe_app.py file
2. Press the run button.


## Instructions for using the software:
1. Select a recipe title to view the recipe details
2. Grab and drag the scroll bar to see the full list of recipes
3. To create a new recipe, select the "New Recipe" button and fill out the details
4. To edit an existing recipe, select it and select the "Edit" button, and change the details.
5. To delete an existing recipe, select it and select the "Delete" button, then select "Yes".
6. To find a recipe, select the search bar and type in your query (you can search both by title and by ingredient)
7. To clear a search query and see all recipe items again, press the "Clear" button.

## Development Environment
To recreate the development environment, you need the following software and/or libraries with the specified versions:
