# Project Title (Update)

GIS Weather Radar Mapping

## Instructions for Build and Use

Steps to build and/or run the software:

1. Pull a basemap from ArcGIS
2. Overlap the weather radar map from OpenWeatherMap
3. Pull temperature data from Open WeatherMap
4. Display satellite radar from Open WeatherMap

Instructions for using the software:

1. Navigate to the weather-radar-map file
2. Right-click on the index.html file
3. Select the first option in the menu, "Open Live Server"
4. Live weather radar map will open in browser window

## Development Environment

To recreate the development environment, you need the following software and/or libraries with the specified versions:

* ArcGIS API key
* OpenWeatherMap API key
